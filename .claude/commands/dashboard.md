# /dashboard — Weekly Dev Progress Report

Run the developer progress dashboard for this project.

```bash
bash /home/finn/Developer/grant-researcher/scripts/dev-dashboard.sh $DAYS
```

Where `$DAYS` defaults to 7. You can pass a number as an argument: `/dashboard 30`

After running the script, summarize the output in a concise report:
- Highlight the current streak
- Note which areas had the most activity
- Flag any gaps in activity (days with no commits)
- End with one encouraging observation about the work done
