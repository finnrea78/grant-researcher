# Skills

Invoke these skills before acting — not after.

## Planning & design
- `grill-me` — stress-test a plan or design before committing to it
- `superpowers:brainstorming` — before adding any feature, component, or new behaviour
- `superpowers:writing-plans` — before touching code on a multi-step task
- `problem-deep-dive` — when exploring a technical problem before deciding on an approach

## Execution
- `superpowers:executing-plans` — when running a written implementation plan with review checkpoints
- `superpowers:subagent-driven-development` — when a plan has independent tasks that can run in parallel
- `superpowers:dispatching-parallel-agents` — when 2+ independent tasks can be worked without shared state
- `superpowers:test-driven-development` — before writing implementation code for any feature or bugfix
- `create-migration` — before scaffolding any Supabase schema change

## Review & finishing
- `simplify` — after completing a logical chunk of code, before committing
- `superpowers:receiving-code-review` — when receiving PR review feedback
- `superpowers:finishing-a-development-branch` — when implementation is done and tests pass

## Work management
- `work-to-be-done` — when deciding what to work on next
- `triage-issues` — when auditing open GitHub issues for staleness or completion
- `dashboard` — weekly dev progress report

## Context & knowledge
- `obsidian-vault` — when updating or searching project context notes (product vision, decisions, research)
- `claude-api` — when touching Anthropic SDK / Claude agent code (prompt caching, streaming, tool use)
