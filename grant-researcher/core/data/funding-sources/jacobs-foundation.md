# Jacobs Foundation

## Schemes

### Jacobs CIFAR Research Fellowship

| Field | Value |
|---|---|
| Status | closed |
| Deadline | typically early February (call opens end of November) |
| Amount | varies |
| Duration | 3 years |
| Career stage | PhD within past 10 years |
| Institutional eligibility | any |
| Thematic priorities | learning variability, reducing inequalities in children's learning, data-informed decision-making; disciplines include education sciences, psychology, economics, sociology, neurosciences |
| Application process | via JCRF Application Portal, in partnership with CIFAR |
| URL | https://jacobsfoundation.org/activity/jacobs-foundation-research-fellowship-program/ |
